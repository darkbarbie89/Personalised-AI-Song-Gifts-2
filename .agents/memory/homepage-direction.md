---
name: Homepage direction
description: User-stated quality bar for the Song Gift homepage.
---

The user wants the homepage to be "modern, vibrant" and to look like "a real sass" rather than a project. They liked the bold redesign, but found a saturated orange hero too strong and asked for real human imagery across the site. They also asked for all site pages to use the same color theme.

**Why:** The user rejected the previously supplied homepage design and asked the agent to create the design instead.

**How to apply:** Keep the expressive SaaS direction, but use orange as an accent rather than a full intense hero background. Use the homepage's cream, soft coral, lime, and dark-ink palette consistently across all pages. Prefer authentic relationship-focused photography across customer-facing pages.
