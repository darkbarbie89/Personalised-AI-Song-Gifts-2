# Build Prompt: Personalised AI Song Gift Website

## Overview
Build a Next.js 14 app (App Router) for a personalised song gift website. Users enter a personal story/memory about someone they love, and the app generates a real, unique song as a gift. The site must look premium and polished — the design quality is critical.

**Important: This will be deployed to Vercel. Do NOT use Replit hosting, Replit DB, or Replit Auth. Use Supabase for everything.**

## Tech Stack
- **Framework:** Next.js 14 with App Router and TypeScript
- **Styling:** Tailwind CSS
- **Database:** Supabase (PostgreSQL + Auth + Storage)
- **Payments:** Stripe Checkout
- **AI Lyrics:** Anthropic Claude API (claude-sonnet-4-6)
- **Song Generation:** Suno via Apiframe (https://apiframe.pro)
- **Package manager:** npm

## Database Schema (Supabase)

### users table (handled by Supabase Auth)

### orders table
```sql
create table orders (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users(id),
  email text not null,
  stripe_session_id text,
  package text not null, -- 'single', 'triple', 'collection'
  credits_total int not null,
  credits_used int default 0,
  amount_paid int not null, -- in cents
  status text default 'active',
  created_at timestamptz default now()
);
```

### songs table
```sql
create table songs (
  id uuid default gen_random_uuid() primary key,
  order_id uuid references orders(id),
  user_id uuid references auth.users(id),
  recipient_name text not null,
  occasion text not null,
  story text not null,
  mood text not null,
  genre text not null,
  lyrics text,
  lyrics_approved boolean default false,
  song_url text, -- mp3 stored in Supabase Storage
  cover_art_url text,
  share_token text unique default gen_random_uuid(),
  status text default 'draft', -- draft, generating_lyrics, lyrics_ready, generating_song, completed, failed
  created_at timestamptz default now()
);
```

## API Routes

### POST `/api/generate-lyrics`
- Takes: recipientName, relationship, occasion, story, mood, genre
- Calls Claude API with a carefully crafted prompt to write song lyrics
- System prompt should instruct Claude to write lyrics in the specified genre/mood, incorporating the personal story details, mentioning the recipient by name naturally, and keeping it to 2 verses + chorus + bridge format
- Returns: generated lyrics text

### POST `/api/generate-song`
- Takes: lyrics, genre, mood
- Calls Apiframe API to generate song via Suno
- The Apiframe endpoint is POST https://api.apiframe.pro/suno/generate
- Request body: { "lyrics": "...", "style": "...", "title": "..." }
- Poll for result or use webhook
- Upload finished MP3 to Supabase Storage
- Update song record with song_url
- Returns: song URL

### POST `/api/create-checkout`
- Creates Stripe Checkout session for the selected package
- Include song details as metadata
- Success URL: /studio/[songId]
- Cancel URL: /create

### POST `/api/webhooks/stripe`
- Handle checkout.session.completed
- Create order record in Supabase
- Create initial song record

## Key Design Principles
1. **Warm and emotional** — this is a gift product, not a tech product
2. **Premium feel** — generous spacing, large text, smooth animations
3. **Mobile-first** — most users will be on phones
4. **Trust signals** — testimonials, "Thousands of songs created", secure payment badges
5. **Colour palette:** Warm gradients — coral (#FF6B6B), amber (#F59E0B), soft pink (#EC4899), deep purple (#7C3AED) as accent. White/cream backgrounds. Dark text.
6. **Typography:** Use 'Outfit' from Google Fonts for headings, 'Inter' for body text
7. **Animations:** Subtle fade-ins on scroll, smooth transitions between form steps
